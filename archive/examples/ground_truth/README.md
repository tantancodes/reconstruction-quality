# Synthetic software examples only

These numbers, IDs, image hashes and geometry hashes are deliberately artificial.
No physical object was measured and no mesh or photographs exist for these records.
They test schema, conversion and error calculations; they are never archival or
real research observations. The expected box relative RMSE is 2% over three check
distances. The 100 mm bar sets a scale of 2 mm per arbitrary coordinate unit and
is excluded from all check aggregates. A synthetic export requires --allow-synthetic
and remains labeled synthetic_test throughout. Never mix it into real datasets.
